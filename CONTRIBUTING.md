# Contributing

I maintain this repo alone and tune it to my own setup and repo conventions: Windows-first tooling, CalVer tags and a strict lint baseline with no suppressions. Things here can break or feel rigid outside that setup, and I change them to suit my repos.

Please open an issue before sending a PR. The codebase has strict style expectations, and a surprise PR that doesn't match them will likely be closed, which wastes your time.

If you want to collaborate or help maintain this, open an issue first so we can agree on style and conventions before any code is written.

Bugs and questions are welcome as issues. Security problems go through [the security policy](.github/SECURITY.md).
